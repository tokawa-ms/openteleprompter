# 操作ガイド

## 原稿を書く

1. 「保存済み原稿」から編集対象を選びます。
2. 「タイトル」に原稿名を入力します。
3. 「本文」に原稿を書きます。
4. 入力内容は自動的にブラウザーへ保存されます。

## 書式を設定する

1. 本文中の文字列を選択します。
2. 「太字」「斜体」「下線」を押すと、選択範囲の書式をオン/オフできます。
3. 色を変更する場合は、カラーピッカーで色を選びます。
4. 書式はテレプロンプター表示にも反映されます。

## 巻き戻し位置を設定する

- 空行で区切った段落は、自動的に「一段落巻き戻し」の基準になります。
- 任意の位置を基準にする場合は、本文中へカーソルを置いて「巻き戻しポイント」を押します。
- 挿入された「↩ 巻き戻しポイント」は編集欄だけに表示され、テレプロンプター本文には表示されません。
- 保存時は `<span data-rewind-point="true">` という制御用タグになり、原稿の表示内容には含まれません。

## 再生する

1. 「再生」を押します。
2. テレプロンプター表示領域が自動で全画面になります。
3. 原稿が設定速度でスクロールします。
4. 全画面中の本文領域を左クリックすると、一時停止/再開を切り替えます。

## 全画面コントロールを使う

全画面中の画面下部には次のコントロールがあります。

| コントロール | 動作 |
| --- | --- |
| 再生/一時停止 | スクロール再生を切り替えます |
| 一行巻き戻し | 現在位置から 1 行分戻します |
| 一段落巻き戻し | 直前の段落または巻き戻しポイントへ戻します |
| 文字サイズ | 全画面中に文字サイズを変更します |
| 速度 | スクロール速度を変更します |
| 行間 | 行間を変更します |

## キーボード操作

| キー | 動作 |
| --- | --- |
| Space | 編集欄以外にフォーカスがある場合、再生/停止 |
| Home | 先頭へ戻る |

## 保存場所

原稿と設定はブラウザーの `localStorage` に保存します。別ブラウザー、別端末、プライベートウィンドウとは共有されません。
