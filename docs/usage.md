# 操作ガイド

このガイドでは、原稿の作成から全画面再生、巻き戻しポイントの利用までを説明します。

## 原稿を作成・選択する

1. 新しい原稿を作る場合は「新規」を押します。
2. 「タイトル」と「本文」を入力します。
3. 別の原稿へ切り替える場合は「保存済み原稿」から選択します。

入力内容は操作のたびにブラウザーへ自動保存されます。「削除」を押すと選択中の原稿を削除します。原稿が 1 件だけの場合は、削除後に空の原稿が残ります。

## 文字へ書式を設定する

1. 本文中の文字列を選択します。
2. 「太字」「斜体」「下線」のいずれかを押します。
3. 同じ書式を解除する場合は、対象を選択して同じボタンをもう一度押します。
4. 文字色を設定する場合は、対象を選択してカラーピッカーから色を選びます。
5. 選択した文字だけを拡大する場合は、「文字強調」の 1.2 倍、1.4 倍、1.8 倍から倍率を選びます。
6. 選択範囲の書式をすべて外す場合は、「選択範囲の装飾解除」を押します。

書式は編集欄、通常のプレビュー、全画面表示へ反映され、原稿と一緒に保存されます。

## 巻き戻し位置を設定する

「一段落巻き戻し」は、次の位置を巻き戻し先として使用します。

- 空行で区切られた段落
- 「巻き戻しポイント」ボタンで挿入した位置

空行を表示上の間として使いたくない場合は、制御用の巻き戻しポイントを使用します。

1. 巻き戻し先にしたい位置へカーソルを置きます。
2. 編集ツールバーの「巻き戻しポイント」を押します。
3. 編集欄に表示される「↩ 巻き戻しポイント」で位置を確認します。

ポイントは原稿内に `<span data-rewind-point="true">` として保存されます。編集欄では位置確認用のラベルとして表示されますが、通常のプレビューと全画面表示には文字や線を表示せず、前後の文字間や行間も広げません。

## 原稿を再生する

1. 必要に応じて文字サイズ、速度、行間、行揃え、左右反転を調整します。
2. 中央の再生操作欄に表示される「想定再生時間」を確認します。
3. 「再生」を押します。
4. テレプロンプター領域が全画面になり、自動スクロールが始まります。
5. 全画面中の本文領域をクリックすると、一時停止と再開を切り替えられます。

原稿の末尾へ到達すると再生は自動停止します。「先頭へ」を押すと再生を停止して先頭へ戻ります。

## 想定再生時間を確認する

「想定再生時間」は、現在の原稿、文字サイズ、行間、速度と全画面表示の大きさから、先頭から末尾まで自動スクロールした場合の時間を `分・秒` で表示します。

- 通常画面では中央の再生操作欄に表示します。
- 全画面表示では画面下部のコントロール内に表示します。
- 原稿、文字サイズ、行間、速度、ウィンドウサイズを変更すると再計算します。
- 一時停止、手動スクロール、巻き戻し操作にかかる時間は含みません。

## 目線ガイドを使う

全画面表示中は、画面上端から 1/3 と 1/2 の高さに点線を表示し、その間を帯状に塗ります。この範囲を目線位置の目安として使用できます。ガイドは通常表示では表示されません。

通常画面の「視線ガイド」では、点線と帯の背景色をそれぞれ選べます。用意された4種類の配色ボタンから選ぶこともでき、変更した配色はブラウザーに保存されます。

## 全画面コントロールを使う

全画面中は画面下部に次のコントロールを表示します。

| コントロール | 動作 |
| --- | --- |
| 再生／一時停止 | 自動スクロールを切り替えます |
| 一行巻き戻し | 現在位置から表示上の 1 行分戻します |
| 一段落巻き戻し | 直前の段落または巻き戻しポイントへ戻します |
| 文字サイズ | 全画面中に文字サイズを変更します |
| 速度 | 全画面中にスクロール速度を変更します |
| 行間 | 全画面中に行間を変更します |

画面下部のコントロールを操作しても、本文クリックによる再生切り替えは発生しません。

## 全画面表示だけを切り替える

画面上部の「全画面表示」を押すと、自動再生を開始せずにテレプロンプター領域を全画面表示できます。元に戻るには、`Esc` などブラウザーの全画面解除操作を使用します。

## キーボード操作

| キー | 動作 |
| --- | --- |
| `Ctrl+Space`（macOS では `Command+Space`） | 再生と停止を切り替えます |
| `Home` | 再生を停止して先頭へ戻ります |

## 保存場所と注意事項

原稿と表示設定は現在のサイトオリジンの `localStorage` に保存します。サーバーには送信されません。

次の環境間ではデータを共有しません。

- 別のブラウザーまたはブラウザープロファイル
- 別の端末
- 通常ウィンドウとプライベートウィンドウ
- ローカル環境、GitHub Pages、Azure Static Web Apps
