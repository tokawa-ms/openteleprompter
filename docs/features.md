# 機能仕様

Open Standalone Web Promptor は、ローカル実行と Azure Static Web Apps ホストを前提にしたブラウザーベースのテレプロンプターです。

## 原稿管理

- 複数原稿をブラウザーの `localStorage` に保存します。
- 原稿ごとにタイトル、本文、更新日時を保持します。
- 「新規」で原稿を追加し、「削除」で現在の原稿を削除できます。
- 最後の 1 件を削除する場合は空の原稿として初期化します。

## リッチテキスト編集

本文編集欄は `contenteditable` ベースです。選択範囲に次の書式を適用できます。

| 書式 | 保存形式 |
| --- | --- |
| 文字色 | `<span style="color: ...">` |
| 太字 | `<b>` |
| 斜体 | `<i>` |
| 下線 | `<u>` |

保存時は許可したタグと色だけをサニタイズし、テレプロンプター表示にも同じ書式を反映します。

## テレプロンプター再生

- 再生開始時にテレプロンプター領域を自動で全画面表示します。
- 再生速度は `requestAnimationFrame` と実数スクロール位置で制御します。
- 低速時でもフレームごとの小さな移動量が失われないよう、内部で小数のスクロール位置を保持します。
- 末尾に到達すると自動停止します。

## 全画面中の操作

全画面表示中は画面下部に専用コントロールを表示します。

- 再生/一時停止
- 一行巻き戻し
- 一段落巻き戻し
- 文字サイズ変更
- 速度変更
- 行間変更

コントロール部分以外のテキストスクロール領域を左クリックすると、再生/停止を切り替えます。

## 日本語表示

- Noto Sans JP をアプリに同梱します。
- `.promptor-text` に `line-break: strict`、`word-break: normal`、`overflow-wrap: normal` を指定し、日本語の禁則処理を優先します。
- `hanging-punctuation: allow-end` も指定しています。ブラウザー対応状況に応じて有効になります。

## 表示設定

- 文字サイズ
- 速度
- 行間
- 行揃え
- 左右反転
- 全画面表示

表示設定も `localStorage` に保存します。
