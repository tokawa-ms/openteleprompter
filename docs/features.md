# 機能仕様

Open Standalone Web Promptor は、ブラウザーだけで動作するクライアントオンリーのテレプロンプターです。ローカル環境、GitHub Pages、Azure Static Web Apps で静的 Web アプリとして実行できます。

## 原稿管理

- 複数の原稿を作成、選択、削除できます。
- 原稿ごとに ID、タイトル、HTML 本文、更新日時を保持します。
- 編集内容はブラウザーの `localStorage` へ自動保存します。
- 最後の 1 件を削除した場合は、空の原稿として初期化します。
- 原稿を切り替えると再生を停止し、スクロール位置を先頭へ戻します。

## リッチテキスト編集

本文編集欄は `contenteditable` を使用します。

| 書式 | 操作 | 主な保存形式 |
| --- | --- | --- |
| 太字 | 選択範囲に対してトグル | `<b>` |
| 斜体 | 選択範囲に対してトグル | `<i>` |
| 下線 | 選択範囲に対してトグル | `<u>` |
| 文字色 | 選択範囲へ選択色を適用 | `<span style="color: ...">` |
| 文字強調 | 選択範囲を 1.2、1.4、1.8 倍に拡大 | `<span data-emphasis="...">` |

太字は Noto Sans JP の 900 ウェイトを使用します。斜体はフォントスタイル合成を許可し、日本語を含む選択範囲にも視覚的な傾きを表示します。

## 巻き戻しポイント

「一段落巻き戻し」は、空行で区切った段落と明示的な巻き戻しポイントを移動先として扱います。

- 編集ツールバーの「巻き戻しポイント」でカーソル位置へ挿入できます。
- `<span data-rewind-point="true">` という制御用タグとして原稿へ保存します。
- 編集欄では「↩ 巻き戻しポイント」というラベルを表示します。
- テレプロンプター本文では幅と高さを持たない不可視の位置情報へ変換し、ラベル、区切り線、余分な文字間や行間を表示しません。
- 空行を入れずに任意の巻き戻し位置を設定できます。

## テレプロンプター再生

- 「再生」を押すとテレプロンプター領域を全画面表示し、自動スクロールを開始します。
- `requestAnimationFrame` と小数のスクロール位置を使い、低速時も移動量を保持します。
- フレーム間の経過時間は最大 0.1 秒として扱い、復帰時の急な移動を抑えます。
- 原稿末尾へ到達すると自動停止します。
- 通常画面の「先頭へ」またはキーボードの `Home` でスクロール位置をリセットできます。

## 想定再生時間

- 全画面幅でレンダリングした原稿のスクロール距離を現在の速度で割り、先頭から末尾までの再生時間を算出します。
- 端数を秒単位で切り上げ、`N分SS秒` の形式で表示します。
- 通常画面の中央操作欄と全画面下部のコントロールへ同じ値を表示します。
- 原稿、文字サイズ、行間、速度、ビューポート、フォントの読み込み状態が変わると再計算します。
- 一時停止、手動スクロール、巻き戻しは計算に含みません。

## 全画面表示

- 画面上端から 1/3 の高さに、目線位置の目安となる青い点線を表示します。
- 画面下部に全画面専用コントロールを表示します。
- コントロール以外の本文領域をクリックすると、再生と一時停止を切り替えます。
- 「全画面表示」ボタンでは、自動再生せずに全画面表示だけを切り替えられます。

全画面専用コントロール:

- 再生／一時停止
- 一行巻き戻し
- 一段落巻き戻し
- 文字サイズ
- 速度
- 行間

## 表示設定

| 設定 | 範囲・選択肢 | 初期値 | 保存 |
| --- | --- | --- | --- |
| 文字サイズ | 24～150 px、2 px 刻み | 42 px | する |
| 速度 | 10～140、2 刻み | 46 | する |
| 行間 | 1.10～2.20、0.05 刻み | 1.55 | する |
| 行揃え | 左、中央、右 | 中央 | する |
| 左右反転 | オン、オフ | オフ | する |

文字サイズ、速度、行間は通常画面と全画面コントロールの間で同期します。

## 日本語表示

- Noto Sans JP の 400、500、700、900 ウェイトをアプリへ同梱します。
- `.promptor-text` に `line-break: strict`、`word-break: normal`、`overflow-wrap: normal` を指定します。
- `hanging-punctuation: allow-end` はブラウザーが対応している場合に有効になります。

## プライバシー

- 原稿と表示設定は現在のブラウザーの `localStorage` だけに保存します。
- 原稿本文を外部 API やアプリケーションサーバーへ送信しません。
- ユーザーアカウント、クラウド同期、エクスポート／インポート機能はありません。
